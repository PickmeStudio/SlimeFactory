# Slime Factory
Это open source игра, вдохновленная Slime Rancher, Satisfactory, Mewgenics, No Man's Sky. Она является геймплейно ориентированной, со стилизованной графикой, процедурной генерацией мира и широким простором для взаимодействия. Игровой геймплей строиться вокруг бактерий, слайм - экосистема с бактериями.
## Геймплей
- Игроку предстоит выводить штаммы бактерий
- Создавать оболочки слаймов для создания экосистемы бактерий
- Исследовать мир
  - Находить новые бактерии с их генами
  - Находить новые материалы для контроля мутаций
- Выполнять заказы и требования от материнской компании
- Игрока спонсирует материнская компания, если он выполняет ее условия
