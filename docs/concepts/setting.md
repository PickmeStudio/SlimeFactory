# Сеттинг игры
Безжизненные планеты и астероиды, которые были заселены бактериями.

## Предыстория
Люди истощили землю, объединили последние ресурсы и создали компанию Биологические Космические Технологии БиоКосТех. Их задача поставлять на землю и другие планеты ресурсы, создаваемыми микроорганизмами.
